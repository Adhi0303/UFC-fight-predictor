Project Overview & Real-World Impact: Developed an end-to-end machine learning platform to predict Mixed Martial Arts (MMA) fight outcomes. By modeling complex fighter dynamics, the system solves the real-world problem of sports volatility, providing sports bettors and analysts with precise statistical edge against traditional Vegas prop betting lines.
Architecture & Data Pipeline: Designed a robust full-stack architecture featuring an automated data ingestion pipeline that scrapes and normalizes historical sports data. Built a high-performance REST API using FastAPI to serve model predictions to a dynamic, responsive frontend crafted with React, Vite, and TailwindCSS.
Machine Learning & Predictive Modeling: Trained and hyperparameter-tuned an XGBoost Classifier on hundreds of complex feature combinations (striking differentials, takedown defense, age, reach). The model achieved a highly competitive baseline prediction accuracy of ~67% on hold-out test sets in a notoriously unpredictable sport.
Monte Carlo Simulation Engine: Engineered a custom Monte Carlo simulator capable of running 10,000 independent fight simulations per matchup in real-time. By sampling historical finish distributions and weighting fighter-specific attributes, the engine accurately predicts granular fight outcomes, including the exact method of victory and the round the fight will end.
